Overview

This CodePen demonstrates how we can animate the opening and closing states of an accordion with fancy reveal animation using only CSS. This concept is suitable for creating FAQ sections, Table of Contents, and more.

How does it work?

CSS Grid allows the accordion to smoothly expand by transitioning grid-template-rows from 0fr to 1fr, without relying on fixed max-height values.

The reveal effect uses clip-path and mix-blend-mode with pseudo-elements, creating a smooth circular animation when the accordion opens and closes.

Inspiration

This CSS-only accordion was inspired by techniques for animating accordion height from zero to auto, combined with a circular reveal effect.
